# 04 · 练习任务书（课堂任务 + 课后作业 + 评分表）

> 课程：Web前端技术 · 第9周 · 全栈基础：前端 ↔ 后端接口交互
> 课时：4 课时（每课时 45 分钟）
> 交付物：一个能跑通"查 + 增"的商品管理页面（可选拓展：删、改）

## 一、课堂任务（课内完成，占过程分）

### 任务 1：跑通 Mock 后端（课时 3，约 15 分钟）

**要求**：

1. 用 `npx json-server --watch db.json --port 3000` 启动服务
2. 浏览器访问 `http://localhost:3000/goods` 能看到 10 条商品数据
3. 手动修改 db.json 里的一个价格，刷新页面确认数据变了

**验收截图**：浏览器里的 JSON 数据页面

---

### 任务 2：用 AI 生成 Mock 数据（课时 3，约 15 分钟）

**要求**：

1. 自己写提示词（可参考模板），让 AI 生成 10 条商品数据
2. 用 AI 结果替换 db.json，重启服务，浏览器验证
3. 把**你用的提示词**保存到 `提示词练习.md`

**验收材料**：提示词文本 + 浏览器验证截图

---

### 任务 3：完成商品管理页面（课时 4，约 30 分钟）

**要求**：补完 `goods-demo-student/main.js` 里的 4 个 TODO

| 功能 | 具体要求 |
|:---|:---|
| ① 加载列表 | 页面打开自动 GET `/goods`，把数据渲染进表格 |
| ② 搜索过滤 | 输入关键词实时过滤商品名，清空后恢复全部 |
| ③ 新增商品 | 填表单 → POST → 提示成功 → 自动刷新列表 → 清空表单 |
| ④ 数据落库 | 打开 db.json 能确认数据真的写进去了 |

**验收**：教师现场检查运行效果 + 控制台无报错

## 二、分层练习（课内做不完 / 想加分的同学）

### 🟢 基础层（必做，人人都要过）

- [ ] 页面加载自动显示商品列表
- [ ] 搜索框能过滤
- [ ] 新增表单能提交成功
- [ ] 控制台没有红色报错

### 🟡 提高层（选做，+10 分）

- [ ] 表单**非空校验**：商品名为空时提示，不发请求
- [ ] 新增成功后自动**清空输入框**（已在答案里）
- [ ] 数据显示"暂无商品"的**空状态**
- [ ] 把价格显示成 `¥79` 的格式

### 🔴 挑战层（选做，+20 分）

- [ ] 每行加【删除】按钮，`DELETE /goods/:id`，删除后刷新列表
- [ ] 删除前弹 `confirm` 二次确认
- [ ] 用**接口搜索**代替前端过滤：`GET /goods?q=关键词`
- [ ] 加**分页**：`GET /goods?_page=1&_limit=5`，配上一页/下一页按钮
- [ ] 用 **Axios 重写**一遍，对比两种写法

### ⚫ 终极挑战（+30 分，衔接第 10–11 周）

- [ ] 加【编辑】按钮，点开弹窗回填数据，用 `PUT /goods/:id` 保存
- [ ] 手写一个"接口层"文件 `api.js`，把所有请求封装成函数，页面只调用不写 fetch

```javascript
// api.js 长这样
export function getGoods() {
  return fetch('http://localhost:3000/goods').then(r => r.json())
}
export function addGoods(data) {
  return fetch('http://localhost:3000/goods', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(data)
  }).then(r => r.json())
}
```
