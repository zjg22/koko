# 01 · 环境准备说明（教师版 / 学生版通用）

> 第9周《前端 ↔ 后端接口交互》课前需要准备好三样东西：**Node.js**、**VS Code + Live Server 插件**、**本周案例文件夹**。
> 建议教师在课前一周把本文档发到班级群，让学生提前装好，课堂上不再花时间配环境。

---

## 一、准备清单（课前）

| # | 需要的东西 | 作用 | 必须？ |
|:-:|:---|:---|:-:|
| 1 | Node.js（含 npm） | 运行 json-server，提供假后端接口 | ✅ 必须 |
| 2 | VS Code | 写代码 | ✅ 必须 |
| 3 | Live Server 插件 | 用 http 协议打开页面（避免 file 协议跨域） | ✅ 必须 |
| 4 | 现代浏览器（Chrome / Edge） | F12 看 Network 面板 | ✅ 必须 |
| 5 | 联网 | 首次运行 `npx json-server` 需要下载包 | ⚠️ 见下方离线方案 |

## 二、检查 Node.js 是否装好

按 `Win + R`，输入 `cmd`，回车，在黑窗口里输入：

```bash
node -v
npm -v
```

**正常结果**：分别显示版本号，例如 `v20.11.0` 和 `10.2.4`。

| 现象 | 说明 | 处理 |
|:---|:---|:---|
| 显示 `v18` / `v20` / `v22` 等 | ✅ 装好了 | 无需处理 |
| 提示"不是内部或外部命令" | ❌ 没装或没配环境变量 | 按第三节安装 |

> 版本要求：Node ≥ 16 即可。太老的版本（v14 以下）json-server 可能跑不起来。

---

## 三、安装 Node.js（没装的同学）

1. 打开官网 https://nodejs.org ，下载左边那个 **LTS 长期支持版**（绿色按钮）
2. 双击安装包，一路 **Next**，中间那个"Automatically install the necessary tools"**不要勾**
3. 装完**重新打开一个 cmd 窗口**，再执行 `node -v` 验证

> 国内下载慢的备选：https://npmmirror.com 首页有 Node 镜像下载入口。

---

## 四、安装 VS Code 与 Live Server 插件

1. VS Code：https://code.visualstudio.com 下载安装
2. 打开 VS Code → 左侧第五个图标（Extensions 扩展）→ 搜索 **Live Server**
3. 找到作者是 **Ritwick Dey** 的那个，点 Install

**为什么必须用它？**

| 打开方式 | 地址栏 | 请求后端 | 结果 |
|:---|:---|:---|:---|
| 双击 html 文件 | `file:///C:/...` | `http://localhost:3000` | ❌ 跨域报错 |
| Live Server | `http://127.0.0.1:5500` | `http://localhost:3000` | ✅ 正常 |

> 这是本周学生最容易踩的第一个坑，课堂上一定要演示一次"双击打开报错 → 用 Live Server 打开正常"。

## 六、第一次启动 json-server（务必提前试一次）

在 `week9/code/mock-goods` 文件夹里：

1. 地址栏里输入 `cmd` 然后回车（**这样打开的窗口已经在这个目录里了**，不用 cd）
2. 输入命令：

```bash
npx json-server --watch db.json --port 3000
```

3. 第一次会问 `Need to install the following packages... Ok to proceed? (y)`，输入 `y` 回车
4. 等待下载，看到下面这段就是成功了：

```
  \{^_^}/ hi!

  Loading db.json
  Done

  Resources
  http://localhost:3000/goods

  Home
  http://localhost:3000
```

5. 打开浏览器访问 **http://localhost:3000/goods** ，能看到 10 条商品 JSON 数据

> ⚠️ **这个黑窗口不能关！** 关掉 = 后端服务停止 = 前端请求全部失败。

## 七、课堂网络不通的备选方案（教师提前准备）

`npx json-server` 首次运行需要联网下载约 20MB 的包。如果机房断网或下载极慢：

**方案 A：课前预装全局包（推荐）**

教师自己电脑在有网时执行一次：

```bash
npm install -g json-server
```

之后学生启动命令改成：

```bash
json-server --watch db.json --port 3000
```

**方案 B：离线拷贝**

在有网的电脑上执行一次 `npm install -g json-server`，然后把全局 `node_modules` 目录打包，拷贝到学生机对应位置。

**方案 C：纯前端兜底（不讲跨域，只讲数据渲染）**

如果实在跑不起来，可以用 `fetch('./db.json')` 读取本地文件演示数据渲染，但这样就看不到"真正的接口"了，只能作为最后兜底。
