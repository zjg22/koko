## 必须讲透的三个类比

**1. 奶茶店点单（解释 HTTP 是什么）**

```
前端（你）          后端（奶茶店柜台）
   │                      │
   │── 我要一杯珍珠奶茶 ──▶│     ← 请求 Request
   │                      │
   │◀──── 给您，做好了 ────│     ← 响应 Response
   │                      │
   └─ 接口 = 点单窗口      │
      地址 = /goods        │
      GET  = 问"有什么"     │
      POST = 下单"要新增"   │
```

**2. 状态码的生活翻译**

| 状态码 | 生活场景 |
|:---|:---|
| 200 | 店员说"好的，给您" |
| 201 | "做好了，这是新增的那杯" |
| 400 | "你说的是啥？菜单上没有啊" |
| 401 | "你还没登录 / 没有会员卡" |
| 404 | "这个窗口不存在，走错店了" |
| 500 | "店员自己手滑把机器弄坏了" |

**3. JSON 是什么**

> "JSON 就是前后端之间**约定好的普通话**。后端不管用 Java、Python 还是 Node 写，吐出来的都是这一串文本；前端不管用原生 JS 还是 Vue，都能把它翻译成自己认识的对象。"

## 现场找错环节（36–44 分钟）

把下面这段投影出来，让学生找几处错：

```javascript
{
  id: 1,                    // ❌ 键名没加双引号
  'title': '无线鼠标',      // ❌ 用了单引号
  "price": 79,
  "stock": 100,
  "remark": undefined,      // ❌ JSON 不支持 undefined
  "sayHi": function(){}     // ❌ JSON 不支持函数
}
```

正确答案：JSON 里键名必须双引号、不能有函数和 undefined。

| 38–45 | **跨域** | 现场制造一次跨域错误，再修好 |

## 关键演示点

### 演示点 1：`res` 不是数据（10–22 分钟）

```javascript
// 让学生先在控制台看这个
const res = await fetch(url)
console.log(res)        // Response 对象，看不到商品数据！
console.log(res.status) // 200

const data = await res.json()
console.log(data)       // 这里才是真正的数组
```

**板书**：`fetch` 拿到的是"信封"，`res.json()` 才是"拆开信封拿信纸"。

### 演示点 2：POST 的两个"不能漏"（22–32 分钟）

```javascript
fetch(url, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },  // ① 漏了：后端收不到/解析不了
  body: JSON.stringify(newGoods)                     // ② 漏了：发出去的是 [object Object]
})
```

**现场翻车**：故意把第 ② 行写成 `body: newGoods`，打开 db.json 看数据变成什么样子，让学生印象深。

### 演示点 3：制造一次跨域（38–45 分钟，本节高潮）

1. 先**双击** `demo-01-fetch-get/index.html`（file 协议）→ 点击按钮 → 控制台报 CORS 错误
2. 让学生念一遍报错：`Access to fetch at ... has been blocked by CORS policy`
3. 再用 **Live Server** 打开同一个文件 → 数据正常出来了
4. 解释：不是代码错了，是**浏览器的同源策略**在拦

**同源三要素**（板书，画三个格子）：

```
http://  localhost  :3000 /goods
└──┬──┘  └───┬────┘ └─┬─┘
  协议      域名     端口
   三个全部一样 = 同源
   有一个不同   = 跨域
```

**必须强调**：跨域只存在于**浏览器**。后端调后端、Postman 调接口，都不存在跨域。

# 课时 3：AI 辅助生成 Mock 接口（json-server）

## 时间轴

| 时间 | 教师动作 | 要点 |
|:---|:---|:---|
| 00–05 | **Mock 是什么** | 后端还没写好，先用假接口把前端跑通 |
| 05–20 | **三步搭建演示** | 建文件夹 → 写 db.json → 敲命令 |
| 20–35 | **AI 生成 Mock 数据** | 给提示词模板，学生自己生成 10 条 |
| 35–45 | **AI 生成接口文档** | 演示提示词 + 对比手写文档 |

## 三步搭建（05–20 分钟，跟着敲）

**第一步**：新建文件 `db.json`

```json
{
  "goods": [
    { "id": 1, "title": "无线鼠标", "price": 79, "stock": 100 },
    { "id": 2, "title": "机械键盘", "price": 199, "stock": 56 }
  ]
}
```

**第二步**：在这个文件夹里打开 cmd，敲：

```bash
npx json-server --watch db.json --port 3000
```

**第三步**：浏览器访问验证

```
http://localhost:3000/goods      → 全部商品
http://localhost:3000/goods/1    → id=1 的那一条
```

> **课堂提醒**：`--watch` 的意思是"盯着 db.json，改了立刻生效"。让学生手动改一下价格，刷新页面看变化。

## AI 生成 Mock 数据（20–35 分钟）

投影提示词模板，让学生复制粘贴到 AI 工具：

```
帮我生成 json-server 用的 db.json，资源名称是 goods，
字段：id(数字自增)、title(商品名称)、price(价格)、stock(库存)。
生成 10 条真实感的数码商品数据，输出纯 JSON，不要任何多余文字和解释。
```

**检验 AI 结果的三步**（教学生怎么验货）：

1. 复制结果，**替换掉** 原来的 db.json
2. json-server 窗口按 `Ctrl + C` 停掉，重新敲一次启动命令
3. 浏览器刷新 http://localhost:3000/goods 看数据

> ⚠️ 常见翻车：AI 输出被包在 ` ```json ` 代码块里，直接粘进去 json-server 会报错。要提醒学生**只粘花括号里面的部分**。

## AI 生成接口文档（35–45 分钟）

```
基于 json-server 的 goods 资源，帮我写一份简洁的接口文档，
包含：请求方式、URL、请求参数、返回示例。
面向前端开发，要能直接照着调，不要写后端实现细节。
```

**教学点**：对比"手写文档 30 分钟" vs "AI 生成 30 秒 + 人工校对 2 分钟"。

## 分步敲代码（05–30 分钟）

**第 1 块：渲染函数（5 分钟）**

```javascript
function render(list) {
  tableBody.innerHTML = ''
  list.forEach(item => {
    const tr = document.createElement('tr')
    tr.innerHTML = `
      <td>${item.id}</td>
      <td>${item.title}</td>
    `
    tableBody.appendChild(tr)
  })
}
```

**第 2 块：请求数据（8 分钟）**

```javascript
async function loadGoods() {
  const res = await fetch(baseUrl)
  goodsList = await res.json()
  render(goodsList)
}
loadGoods()
```

> 敲完立刻刷新页面看效果 —— **每加一小块就要看到结果**，这是保持零基础学生注意力的关键。

**第 3 块：搜索（5 分钟）**

```javascript
searchInput.oninput = function () {
  const kw = this.value.trim().toLowerCase()
  const filterList = goodsList.filter(item => item.title.toLowerCase().includes(kw))
  render(filterList)
}
```

**第 4 块：新增（12 分钟）**

```javascript
addBtn.onclick = async function () {
  const newGoods = {
    title: titleInp.value,
    price: Number(priceInp.value),
    stock: Number(stockInp.value)
  }
  const res = await fetch(baseUrl, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(newGoods)
  })
  if (res.ok) {
    alert('新增成功！')
    loadGoods()
  }
}
```

**验证动作**：让学生打开 db.json 文件，确认新增的数据**真的写进去了**。

## Network 面板教学（重点技能）

手把手带学生做一遍：

1. `F12` → 点 `Network` 标签
2. 回到页面点"提交新增"按钮
3. Network 里出现一条新记录，点它
4. 依次看四个地方：

| 看哪里 | 看什么 | 正常应该是什么 |
|:---|:---|:---|
| Headers → Request URL | 请求地址 | `http://localhost:3000/goods` |
| Headers → Request Method | 请求方法 | `POST` |
| Headers → Status Code | 状态码 | `201 Created` |
| Payload → Request Payload | 发出去的数据 | `{"title":"...","price":...}` |
| Response | 后端返回 | 新增好的商品对象（含 id） |

> 这一页要慢，让学生真的点一遍。会看 Network 面板 = 以后能自己排错一半的问题。
