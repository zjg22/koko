## 第 0 步：确认三件事装好了

打开 cmd（`Win + R` → 输入 `cmd` → 回车），输入：

```bash
node -v
```

| 看到什么 | 怎么办 |
|:---|:---|
| `v18.xx.x` / `v20.xx.x` 等版本号 | ✅ 装好了，继续下一步 |
| "不是内部或外部命令" | ❌ 去看 `01-环境准备.md` 第三节装 Node |

VS Code 里搜 **Live Server** 插件，确认已 Install。

## 任务 A：启动一个"假后端"（约 5 分钟）

### A1. 找到 db.json

进入 `week9/code/mock-goods` 文件夹，里面有一个 `db.json`。

### A2. 在这个文件夹里打开命令行

**最简单的方法**：点一下文件夹的地址栏（就是显示路径那条），输入三个字母：

```
cmd
```

然后按回车。弹出的黑窗口，左边显示的路径就是这个文件夹。

> 这样打开的好处是：不需要 cd 半天。

### A3. 敲启动命令

```bash
npx json-server --watch db.json --port 3000
```

第一次会问你要不要装包，输入 `y` 回车，然后等它下载。

**✅ 做对了会看到**：

```
  \{^_^}/ hi!

  Loading db.json
  Done

  Resources
  http://localhost:3000/goods
```

### A4. 浏览器验证

打开 Chrome / Edge，地址栏输入：

```
http://localhost:3000/goods
```

**✅ 做对了会看到**：一整页白色背景的 JSON 数据，里面有 10 条商品。

```
[
  { "id": 1, "title": "无线鼠标", "price": 79, "stock": 100 },
  { "id": 2, "title": "机械键盘", "price": 199, "stock": 56 },
  ...
]
```

> ⚠️ **黑窗口全程不能关！** 关了就等于后端服务器关机了，后面所有请求都会失败。

### 小实验：改一下数据

用 VS Code 打开 `db.json`，把无线鼠标的价格从 `79` 改成 `88`，保存。

回到浏览器刷新页面 → 价格变成 88 了。

**这就是"数据存在后端"的意思**：改数据不用改前端代码。

## 任务 B：用 fetch 拿数据（课时 2）

### B1. 用 Live Server 打开页面

VS Code 里打开 `week9/code/demo-01-fetch-get/index.html`，
右键 → **Open with Live Server**。

**✅ 做对了会看到**：浏览器地址栏是 `http://127.0.0.1:5500/...`（不是 `file:///`）

### B2. 点按钮看效果

点"点击加载商品数据"按钮，表格里出现 10 行商品。

### B3. 看 Network 面板

按 F12 → Network 标签 → 再点一次按钮

**✅ 做对了会看到**：列表里多出一条 `goods` 记录，点开能看到：

- Request Method: `GET`
- Status Code: `200`

### B4. 故意踩坑（重要！）

关掉 Live Server 页面，**直接双击** `index.html` 文件打开，再点按钮。

**❌ 会看到**：控制台报红色 CORS 错误，表格没数据。

这就是**跨域**。代码一模一样，只是打开方式不同 —— 记住这个感觉。

## 任务 C：用 fetch 新增数据（课时 2）

### C1. 打开 POST 演示

Live Server 打开 `week9/code/demo-02-fetch-post/index.html`

### C2. 填表单提交

```
商品名称：移动电源
价格：149
库存：200
```

点"提交新增"。

**✅ 做对了会看到**：`新增成功！后端给的 id 是 11`

### C3. 验证数据真的存进去了

打开 `week9/code/mock-goods/db.json` 文件，滚动到最下面。

**✅ 做对了会看到**：多了一条

```json
{ "id": 11, "title": "移动电源", "price": 149, "stock": 200 }
```

**这就是"POST 会修改服务器数据"的意思。**

### C4. 翻车实验（可选）

把代码里的 `body: JSON.stringify(newGoods)` 改成 `body: newGoods`，
再提交一次，看看 db.json 里变成什么。

答案：会变成一堆乱七八糟的东西或者报错 —— 这就是为什么要 `JSON.stringify`。

## 任务 D：让 AI 帮你造数据（课时 3）

复制下面这段话，粘贴到任意 AI 工具（豆包 / 通义 / 文心 / ChatGPT 都行）：

```
帮我生成 json-server 用的 db.json，资源名称是 goods，
字段：id(数字自增)、title(商品名称)、price(价格)、stock(库存)。
生成 10 条真实感的数码商品数据，输出纯 JSON，不要任何多余文字和解释。
```

**拿到结果后三步走**：

1. **只复制花括号 `{ }` 里面的内容**（不要连 ```json 一起复制！）
2. 用它**替换** db.json 的全部内容，保存
3. json-server 窗口按 `Ctrl + C` 停掉，重新敲一次启动命令，刷新浏览器

**✅ 做对了会看到**：10 条全新的商品数据

> 💡 进阶：把提示词里的"数码商品"改成"零食"或"图书"，看看 AI 会不会跟着改。

## 任务 E：完成商品管理页面（课时 4）

### E1. 拿到练习文件

`week9/code/goods-demo-student/` 里有两个文件：

- `index.html` —— **已经写好了，不用改**（页面结构 + 样式）
- `main.js` —— **要你补完**，里面有 4 个 TODO

### E2. 用 Live Server 打开

右键 `index.html` → Open with Live Server

**现在的样子**：表格是空的（因为 main.js 里的函数还空着）

### E3. 依次补完 4 个 TODO

打开 `main.js`，按注释里的提示，一块一块补：

| TODO | 要做什么 | 补完后的效果 |
|:-:|:---|:---|
| 1 | 写 `render` 函数 | 能把数组画成表格 |

> **每补完一块就刷新页面看一次**，不要一口气写完再验证。

### E4. 自检清单（做完自己打勾）

- [ ] 刷新页面，表格自动出现 10 条商品数据

- [ ] F12 控制台**没有红色报错**

### E5. 卡住了怎么办

按顺序试：

1. 看控制台红色报错，读一遍说了什么
2. 翻 `05-排错手册.md` 对照
3. 把**报错 + 你的代码**一起粘给 AI（模板见 `06-AI提示词模板.md`）

## 常用命令速查卡

```bash
# 启动假后端（在 mock-goods 文件夹里执行）
npx json-server --watch db.json --port 3000

# 停止服务
Ctrl + C

# 检查 Node 版本
node -v

# 换个端口（3000 被占用时）
npx json-server --watch db.json --port 4000
```

## 常用网址速查卡

| 地址 | 作用 |
|:---|:---|
| http://localhost:3000/goods | 看全部商品数据 |
| http://localhost:3000/goods/1 | 看 id=1 的商品 |
| http://localhost:3000/goods?q=鼠标 | 按关键词搜索（后端过滤） |
| http://localhost:3000/goods?_page=1&_limit=5 | 分页，第 1 页 5 条 |
