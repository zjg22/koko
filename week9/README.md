# 第9周 · 全栈基础：前端 ↔ 后端接口交互（AJAX / Fetch）

> 课程：Web前端技术 · 专升本·软件工程（二年级）
> 课时：4 课时 × 45 分钟
> 学情：有基础 JS，无后端经验，对 HTTP / 接口 / 跨域完全陌生
> 定位：**讲概念、看现象、跑通闭环**，不深挖底层原理

---

## 一、本周四节课在干什么

| 课时 | 主题 | 学生产出 |
|:-:|:---|:---|
| 01 | HTTP 基础 · GET/POST · JSON · 接口规范 | 能手写一段合法 JSON，能分清 GET 和 POST |
| 02 | Fetch / Axios · 跨域概念 | 能用 fetch 发 GET 和 POST，知道跨域是怎么来的 |
| 03 | json-server 搭建 Mock 后端 | 能一键起后端，能用 AI 造 Mock 数据 |
| 04 | 前端联调：渲染列表 · 搜索 · 新增 | 一个能跑通"查 + 增"的商品管理页面 |

**一句话主线**：数据不再写死在代码里 → 存在后端 → 前端发请求去拿 → 拿到后渲染到页面。

## 三、上课流程（照这个顺序走）

### 课前

1. 把 `docs/01-环境准备.md` 发班级群，让学生提前装 Node 和 Live Server
2. 自己先跑一遍 `npx json-server --watch db.json --port 3000` 确认能起
3. 把 `code/goods-demo-answer` 从学生可见目录挪走，防止直接抄

### 课中

```
课时1  概念为主：奶茶店类比 → 请求三部分 → GET/POST → 状态码 → JSON 找错
课时2  动手为主：Promise 回顾 → fetch GET → fetch POST → 故意制造跨域
课时3  出成果：  json-server 三步走 → AI 造数据 → AI 写文档
课时4  出成果：  分步补 TODO → 验证落库 → AI 排错演示 → Network 面板
```

> **节奏提醒**：每 10 分钟必须让学生动一次手。详细脚本见 `docs/02-教师演示脚本.md`。

### 课后

- 收 `docs/04-练习任务书.md` 里规定的提交物
- 按评分表打分（功能 40 / 规范 20 / 排错 20 / AI 10 / 过程 10）

## 四、三个必须让学生记住的点

| # | 记住什么 | 怎么验证 |
|:-:|:---|:---|
| 1 | **GET 查，POST 增** | 随机提问：加载列表用哪个？提交表单用哪个？ |
| 2 | **fetch 拿到的是信封，res.json() 才是信纸** | 让他解释代码里为什么有两个 await |
| 3 | **跨域是浏览器拦的，不是代码错了** | 双击打开报错 → Live Server 打开正常 |

---

## 五、授课红线（适配专升本学生）

1. **不讲** TCP、HTTP 报文格式、三次握手
2. **不讲** 复杂 CORS 配置，只讲现象 + 本周解法（Live Server / json-server）
3. **明确告诉学生**：json-server 是练习用的假后端，真实项目后端不是它
4. **AI 是助手不是替身**：AI 给的代码必须读懂，课上随机抽人解释任意一行
5. **衔接第 10–11 周**：Trae 里自带数据库和接口，本质就是今天这套 CRUD 思想
