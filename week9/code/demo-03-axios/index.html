演示3：Axios 对比 Fetch（拓展内容）

fetch（浏览器原生）

fetch('http://localhost:3000/goods')
  .then(res => res.json())   // 要手动转
  .then(data => console.log(data))
  .catch(err => console.error(err))

axios（第三方库）

axios.get('http://localhost:3000/goods')
  .then(res => {
    console.log(res.data)    // 已经转好了
  })
  .catch(err => console.error(err))
对比项fetchaxios
来源浏览器自带需要安装 / 引 CDN
JSON 转换手动 res.json()自动，直接用 res.data
POST 请求体手动 JSON.stringify传对象即可，自动转
错误处理404/500 不算失败自动进 catch
企业使用较少非常常见

本节课先用 fetch 打底，理解底层；后面 Trae 项目里遇到 axios，看到 .get / .post 能认出来就行。
